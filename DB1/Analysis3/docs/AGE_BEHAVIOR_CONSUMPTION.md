# 연령별 행동 변화와 소비 변화 연결

Analysis2의 동 × 연령 × 월 행동 탐지에 Analysis1의 반기 지역 유형과 Analysis3 소비 근거를 연결한다. 기존 탐지 신호, 임계값, 고립 후보 여부는 변경하지 않는다.

## 조회와 산출물

- `v_a23_age_monthly`: 동 × 연령 × 월 × 탐지 모델 요약. `payload_json`에 기존 행동 신호, 지역 유형, 소비 비교 가능 분야 수와 근거 목록이 있다.
- `v_a23_age_detail`: 위 키 × 소비 분야. SQL의 `domain`과 JSON의 비교 지표로 상세 조회한다.
- `v_a23_age_quarter`: 월별 행동 신호 목록과 분기 소비 근거를 한 번씩 저장한다. `observed_months`, `fully_assessed_months`로 결측을 확인한다. 분기 소비를 3개월의 독립 근거로 합산하지 않는다.
- `v_a23_age_available_context`: 사건 월말까지 알려진 공표일이 있는 소비 자료만 연결한다. 공표일 미확인 자료는 이 조회에서 제외된다.
- `outputs/integrated/analysis23_age_*.csv`는 해당 DB 조회의 펼친 결과다. `age_signal_consumption_context.csv`는 행동 신호가 있는 행만 모은 검토 자료다.

```sql
SELECT adm_cd,date,age_band,
       json_extract(payload_json,'$.communication_signal') AS communication_signal,
       json_extract(payload_json,'$.social_market_down_domains') AS social_market_down_domains,
       json_extract(payload_json,'$.evidence_label') AS evidence_label
FROM v_a23_age_monthly
WHERE json_extract(payload_json,'$.behavior_signal')=1;
```

## 연결 규칙과 해석

연령 대응은 20s→20대, 30s→30대, 40s→40대, 50s→50대, 60plus→60대이상이다. 통신 자료가 없는 10대는 소비 자료에 존재해도 행동 탐지와 연결하지 않는다.

상권은 같은 행정동의 점포를 이용한 고객 연령별 소비이며, 통신 추정 거주자의 행동과 동일 개인 관측이 아니다. 해당 동의 해당 연령 주민 소비로 단정하지 않는다. `market_change_pct`는 동일 업종을 맞춘 과거 동일 분기 일평균 거래건수 대비 변화다. `market_below_prior_min`은 비교 가능 과거 동일 분기의 최솟값보다 낮음을 뜻한다. 10월 행동에 2025Q4 소비를 연결하는 것은 분기를 돌아보는 사후 비교이며 10월 소비 측정이나 행동 이후의 인과 효과가 아니다.

신한카드는 강남구 점포의 연령별 소비다. 동별 카드 관측으로 추정하거나 각 동의 독립 증거로 합산하지 않는다. `card_change_pct`는 동일 업종을 맞춘 전월 대비 일평균 거래건수 변화다. 최초 월은 비교값이 없고, 현재 자료는 계절성 과거 비교가 불가능하다. 상권과 카드의 업종 및 변화 기준도 같지 않다.

외식카페(A), 여가운동(B), 대면생활서비스(C)는 사회적 접촉 기회와 관련된 보조 분야다. 생활필수(D), 의료건강(E)는 생활 맥락으로 함께 제공한다. A~C 감소만으로 사회적 고립을 확정하지 않는다. 집계치의 겹침은 개인 고립, 인과성 또는 탐지 정확도의 검증이 아니다. 현재 `consumption_isolation_score`는 미정이며 소비 결측·비교 불가는 NULL이다.

## 업데이트

기존 `run_db1.ps1 -Command scan`, `analysis3`, `export`와 `analysis2-age-detect` 실행 후 연결 결과가 재생성된다. 신규 행동 월을 먼저 확보하면 소비는 비교 불가로 저장되며, 해당 월 카드 또는 분기 상권 자료가 도착한 뒤 재실행하면 근거가 연결된다. 기존 Analysis3의 스냅샷·과거 기준 보호 규칙을 그대로 사용한다. 공표일은 원본과 확인한 날짜를 설정한 경우만 사용한다.

기존 `v_a123_detail`은 동 전체 행동 신호에 소비 연령을 펼친 과거 조회다. 동·연령별 행동 근거에는 새 `v_a23_age_*`를 사용한다. 각 모델 버전은 별도 키이므로 여러 모델을 함께 조회할 때에는 모델 버전을 선택한다.

## 이번 실행 결과

월별 660행, 분야별 3300행, 분기별 220행. 행동 신호 10건 모두 통신 관계망 감소 신호이며 이동 감소·복합 후보는 기존과 동일하게 0건이다. 10건 모두 A~C 중 하나 이상에서 분기 거래 감소 및 과거 동일 분기 최솟값 미만이 관측되었다. 10건 모두 같은 연령의 강남구 카드 A~C 중 하나 이상에서 전월 대비 감소가 있었으나 이는 동별 근거가 아니다. 공표일이 없는 현재 자료는 공표일 기준 조회에서 상권·카드 모두 연결되지 않는다.

예: 2025년 10월 신사동 30대 통신 변화 신호에 2025Q4 외식카페 상권 거래 -17.43% 변화와 강남구 30대 10월 카드 거래 -8.98% 변화를 보조 근거로 연결했다. 두 수치는 비교 기간·모집단이 다르다.

동일한 A~C 분야에서 상권과 카드가 함께 감소한 행동 신호는 9건이다. 분야 대응은 분석용 공통 분류이며 업종 원천 체계가 동일하다는 뜻은 아니다.

검증: Analysis3 및 새 연결 테스트 32개, DB1 루트 테스트 8개 통과. 신규 월 추가·소비 지연 도착·연령 교차 오연결 방지·공표일과 분기 완료 조건·NULL·재실행·기존 행동 신호 보존을 검증했다. 전체 내보내기 실행도 완료했으며 기존 DB 테이블 내용과 무결성을 확인했다. 실제 2026년 원본 자료의 전체 업데이트 검증은 별도다.
