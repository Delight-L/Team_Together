# Analysis2 소통 활동 수준·회복 추적

2026-10-07 추가. 기존 변화 탐지와 별도로, 신호 이후 소통 수준이 발생 직전 월의 비교 기준으로 돌아왔는지 추적한다. 사회적 고립 확정, 장기 저활동 위험 모형, 유의성 검정 또는 위험 점수는 아니다. 현재 구현 범위는 전화·문자 대상자 수다. 이동 수준을 같은 규칙으로 판정하지 않는다.

## 비교 기준

1. `raw_change_pct`: 해당 동·연령의 현재 값 / 신호 발생 직전 월 값 - 1.
2. `seasonal_change_pct`: 현재 값과 직전 기준 월 값을 각각 **2022-01~2025-06 고정 기준선의 같은 달 중앙값**으로 나눈 뒤 두 정규화 수준의 비율을 비교한다. 월별 유효 이력 최소 3개가 필요하다.
3. `common_change_pct`: 같은 연령·같은 두 기간으로 계산한 각 동의 정규화 수준 비율 중앙값. 최소 11개 동이 필요하다. 대상 동을 포함하며 인구 가중 구 전체 평균이 아니다.
4. `local_change_pct`: 대상 동의 정규화 수준 비율 / 구 중앙값 비율 - 1. 구 공통 변화와 비교했을 때 해당 동의 잔여 변화다.

같은 달 정규화는 계절성 진단용 단순 기준이다. 과거 3~4년 중앙값으로 요일·공휴일·장기 추세·제공기관 산출 정의 변화까지 보정했다고 주장하지 않는다. 공휴일 정의 및 독립적인 시계열 모형 검증은 남아 있다. 원자료와 정규화·상대 결과를 반드시 함께 설명한다.

## 상태값과 품질

각 비교 경로를 독립적으로 표시한다.

| 상태 | 의미 |
|---|---|
| `both_below_reference` | 전화·문자가 모두 해당 비교 기준보다 낮음 |
| `recovered_to_reference` | 전화·문자가 모두 해당 비교 기준 이상 |
| `mixed_recovery` | 두 지표의 회복 방향이 엇갈림 |
| `unavailable` | 한 지표라도 비교할 수 없음 |

부호와 기준 수준의 관계를 표시할 뿐, 작은 차이가 통계적으로 유의한 악화·회복이라는 뜻은 아니다. 상대 경로에서 기준 이상이라는 결과가 절대 수준 회복을 뜻하지 않는다. 과거 수준 자체가 높거나 낮았는지도 이 상태만으로 판단하지 않는다.

지표가 양수·유한값, 유효 추정 인구 200 이상, 관측 비율 80~100%여야 한다. 전월 기준값이 없거나 유효하지 않으면 이전 유효 월로 건너뛰지 않고 비교 불가로 둔다. `consecutive_both_below_months`는 같은 달 정규화 경로에서 두 지표가 모두 낮은 인접 집계월 수이며, 독립적인 위험 사건 수가 아니다. 일부 원천 지표의 집계 창이 중첩되고 같은 개인을 추적하지 않는다.

## DB 저장과 AI agent 조회

- `a2_activity_model`: 설정·고정 기준선 지문·버전.
- `a2_activity_level`: 동·연령·월 원값, 같은 달 기준값·기간·품질, 정규화 수준.
- `a2_activity_followup`: 신호별 후속 월과 세 경로의 변화·상태. 소통 또는 이동 신호가 있는 집단을 대상으로 소통 수준을 추적하며 최초 신호 도메인을 보존한다.
- `v_a2_activity_followup`: 전체 신호 후속 월 조회.
- `v_a2_activity_followup_latest`: 각 최초 신호의 최신 후속 월 조회.

```sql
SELECT adm_cd, age_band, signal_date, date,
       raw_state, seasonal_state, local_state, payload_json
FROM v_a2_activity_followup_latest;
```

기존 `a2_age_detection`의 `communication_signal`, `mobility_signal`, `combined_signal`과 별도 정보다. 낮은 수준 지속을 기존 탐지의 `Continuing`으로 바꾸거나 결합 고립 후보로 승격하지 않는다. 소비의 월·분기 구분과 구 조사 배경의 한계도 유지한다. 현재 데이터의 이용 가능 시점이 완전히 검증되지 않아 결과는 사후 설명용이며 당시 실시간 이용 가능성을 보장하지 않는다.

## 실행과 업데이트

```powershell
.\run_db1.ps1 -Command analysis2-activity
.\run_db1.ps1 -Command scan
.\run_db1.ps1 -Command export
```

`analysis2-age-detect`, 일반 Analysis2 월 처리 및 `scan`/`watch` 이후 Analysis3 연결 단계에서 함께 계산한다. 새 파일은 기존 전처리·탐지를 거쳐 DB에 적재돼야 하며 자동 다운로드 기능은 없다. 원천 자료·동 코드·전처리 요구사항은 기존 규칙을 따른다. 미래 월에는 같은 월의 고정 기준값과 새 월 동별 관측을 사용해 후속 행만 추가한다. 기존 신호별 기준 월은 바꾸지 않는다.

같은 입력 재실행은 중복을 만들지 않는다. 기존 후속 결과가 달라지면 덮어쓰기를 차단한다. 고정 기준선·설정 변경은 명시적 모델 이전이 필요하며 이 모듈은 자동 이전하지 않는다. 월 누락·서비스 셀 누락·중복 키도 차단한다. 내보내기는 `Analysis2/outputs/activity_level/`의 `activity_level.csv`, `activity_followup.csv`, `activity_followup_latest.json`이다.
