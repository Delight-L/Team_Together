# Analysis2 동·연령별 변화 탐지

2026-10-07 구현. 분석 단위는 강남구 22개 동 × 20s·30s·40s·50s·60plus × 월이다. 5세 단위 자료는 보존하며 이번 운영 탐지는 다섯 연령대에서 수행한다. 2022-01~2025-06으로 기준을 구축하고 2025-07부터 탐지한다.

## 무엇을 탐지하는가

통화 대상자와 문자 대상자가 함께 감소하면 소통 신호, 평일과 휴일 이동 횟수가 함께 감소하면 이동 신호다. 둘이 같은 동·연령·월에서 겹칠 때 `isolation_related_candidate`로 표시한다. 관심집단 비율 증가와 이동거리 감소는 별도 보조 근거로 붙인다. 이 결과는 집단의 고립 관련 행동 변화 탐색이며 실제 사회적 고립이나 개인의 고립을 확정하지 않는다. 단독 소통 감소는 SNS 등 대체 소통 가능성도 확인해야 한다.

## 비교 방식

각 지표는 같은 동·연령의 전월 대비 로그 변화를 계산한다. 현재 월 이전의 유효한 이력만 사용해 중앙값/MAD 기준 robust z를 구한다. 두 경로를 저장한다.

- `absolute`: 실제 변화가 해당 동·연령의 과거 변화와 비교해 이례적인가.
- `local`: 같은 달·같은 연령의 유효한 동들에서 계산한 중앙값을 제거한 뒤 해당 동·연령의 과거와 비교한다.

한 경로에서 판정 가능하면 그 경로로 도메인을 평가한다. 실제 값이 감소하지 않았는데 다른 동보다 덜 증가한 경우는 감소 신호로 표시하지 않는다. 강남구 전체의 연령별 공통 변화는 별도 표로 보존한다. 지역 공통 감소를 상대 비교에서 제거하더라도 absolute 경로와 공통 표에서 확인할 수 있다.

## 임계값과 품질

임계값은 연령·지표·경로별로 2025-06까지의 과거만 사용한 z 점수 분포의 하위 2.5% 분위수와 -2.0 중 더 엄격한 값이다. 업데이트 구간은 임계값 보정에 쓰지 않는다. 2025-07 이후 과거 월은 다음 달 z의 expanding 이력에 포함되지만, 보정 임계값은 고정한다. 기본 설정과 실제 임계값은 `age_detection_model.json`에 기록한다.

이 보정은 역사적 하위 꼬리 탐색 기준이다. 2.5%가 고립 발생률, 오탐률, 유의수준 또는 정확도라는 뜻은 아니다. 관련 결과를 확인할 정답 자료가 없어 임계값은 **탐색용**이다. 실제 고립 검증과 민감도·특이도 평가가 추가로 필요하다.

기본 품질 설정은 유효 추정 인구 200 이상, 지표별 유효 인구/총 추정 인구 비율 80% 이상, 유효한 과거 변화 12개 이상이다. 지역 상대 비교는 동 11개 이상의 유효한 변화가 필요하며 임계값 보정은 과거 점수 24개 이상이 필요하다. 200명은 통신사의 실제 표본 수가 아닌 제공된 집계의 유효 추정 인구다. 이 수치들은 초기 운영 품질 기준이며 정확도가 검증된 표본 기준이 아니다.

- 소통·이동을 독립적으로 판정한다. 이동 자료 부족 때문에 소통 판정까지 막지 않는다.
- 판단 불가능한 도메인은 DB에서 `NULL`, 전체 상태는 `partially_assessed`/`deferred`다. 0(신호 없음)으로 바꾸지 않는다.
- 관심집단 구조적 0값은 관심집단 근거를 사용할 수 없는 상태다. 소통·이동의 유효한 관측 자체는 유지한다.
- 과거 MAD가 0이면 작은 상수를 더해 신호를 만들지 않고 판정 보류한다.
- 추정 인구의 전월 변화가 10% 이상, 원본 성별 추정 구성 변화가 5%p 이상이면 검토 이유를 붙인다. 원인을 확정하거나 변화 신호를 자동 삭제하지 않는다. 성별 표준화까지 수행한 모델은 아니다.
- 기상·요일 정보는 결과에 보존하지만 인과적으로 회귀 보정한 값은 아니다.

일부 원천 지표는 최근 3개월 집계가 겹친다. `Continuing`과 인접 신호 길이는 독립된 반복 관측 횟수 또는 위험 악화 증거가 아니다. 판정 불가능한 월 다음의 신호는 `New_after_gap`으로 구분한다. 안정적으로 낮은 활동 수준 자체를 탐지하는 장기 저활동 모형은 이번 변화 탐지와 다르며 아직 구현하지 않았다.

## DB와 결과

기존 동별 분석 표와 연령별 전처리 표는 보존한다. 추가 표:

- `a2_age_model`: 초기 기준 지문·설정·임계값·모델 버전.
- `a2_age_detection`: 동·연령·월·모델 버전별 도메인 신호, 평가 상태, 결과 JSON. 연령별 feature와 외래키 연결.
- `a2_age_common_change`: 월·연령별 강남구 공통 변화와 신호.
- `v_a2_age_detection`: AI agent용 연령별 결과 조회 뷰.

모델 버전은 기준 자료와 설정의 지문으로 고정한다. 동일 실행은 중복 추가하지 않는다. 과거 자료·설정·결과가 달라지면 자동 덮어쓰기를 차단한다. 모델 변경은 명시적 버전 이전이 필요하다. 첫 판정 시 결합한 Analysis1 맥락은 사후 설명이며 탐지 조건에 쓰지 않는다. 과거 판정의 맥락은 재실행 때 보존해 후속 Analysis1 업데이트가 과거 결과를 바꾸지 않게 한다.

`Analysis2/outputs/age_detection/`에 다음 자료를 저장한다.

- `age_detection_signal_list.csv`: 실제 신호가 있는 동·연령·월 목록.
- `analysis2_age_detection.csv`: 전체 업데이트 구간 판정과 근거·품질·맥락.
- `analysis2_age_common_change.csv`: 강남구 공통 변화.
- `age_detection_monthly_summary.csv`: 월·연령별 신호/부분 판정 집계.
- `age_detection_quality_review.csv`: 자료·구성 변화 검토 대상.
- `age_detection_score_history.csv`: 전체 과거 점수와 비교 기준. baseline 구간 신호는 운영 판정이 아닌 진단용이다.
- `age_detection_calibration.csv`, `age_detection_model.json`: 실제 임계값·보정 표본 수·설정.
- `age_detection_baseline_sensitivity.csv`: 기준 구간 임계값별 탐색 빈도. 오탐률 또는 성능 검증 표가 아니다.
- `DETECTION_VALIDATION.md`: 실행 결과와 검증.

## 실행·업데이트

```powershell
.\run_db1.ps1 -Command analysis2-age-detect
.\run_db1.ps1 -Command scan
.\run_db1.ps1 -Command analysis2 -Month 2026-01
.\run_db1.ps1 -Command export
```

일반 Analysis2 월 처리/scan은 원본 전처리와 연령별 이력 추가 후 탐지를 수행한다. 신규 월은 같은 동·연령의 이전 자료와 비교하고 기존 임계값을 유지한다. 원본이 없으면 기다리며 가상 2026년 결과를 운영 DB에 만들지 않는다. 이번 수정에 새로 검토한 월별/분기별 등록인구 CSV는 사용하지 않았다.

AI agent 조회 예:

```sql
SELECT date,adm_cd,age_band,assessment_status,
       communication_signal,mobility_signal,combined_signal,
       isolation_related_candidate,result_json
FROM v_a2_age_detection
WHERE date='2025-10-01'
ORDER BY adm_cd,age_band;
```

DB의 0과 NULL을 구분하고 `review_reasons`, 관심집단 근거 가용성, 모델 버전, 부분 판정을 함께 읽는다. 기존 `v_db1_integrated`/Analysis3 소비 결합은 계속 기존 범위를 사용한다. 연령별 탐지와 Analysis3 소비는 새 `v_a23_age_*` 조회로 연결되었다. 이번 결과를 이미 소비 변화로 교차 확인한 고립 후보로 설명하지 않는다.

연결 구현과 실행을 완료했다. 동·연령·월별 행동 근거에는 `v_a23_age_monthly`와 `v_a23_age_detail`을 사용한다. 분기 집계는 `v_a23_age_quarter`, 공표일 기준 조회는 `v_a23_age_available_context`다. 상세 해석과 업데이트 규칙은 `Analysis3/docs/AGE_BEHAVIOR_CONSUMPTION.md`를 참조한다. 소비는 보조 근거이며 탐지 신호나 고립 점수에 합산하지 않는다.
