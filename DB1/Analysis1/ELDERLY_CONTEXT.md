# 동별 독거노인 통계의 Analysis1 및 동·연령별 분석 연결

## 목적과 위치

독거노인 관측 통계는 동의 고령층 생활구조와 경제적 취약성 맥락을 보완한다. Analysis1 안에 별도 연간 통계로 저장하고, 기존 지역 유형과 동·연령별 행동·소비 조회에 연결한다. 새로운 Analysis4/5는 만들지 않는다. 기존 PCA 입력·기준 모형·반기 유형·행동 임계값·소비 지표는 보존한다. 지역 유형 재학습은 이번 작업 범위가 아니다.

## 원본과 정의

- 원본: `서울시 공공데이터/원본/201_DT_201004_F030011_20261006165435.csv`.
- 공식 설명: [서울 데이터 허브 독거노인 현황(성별/동별)](https://data.seoul.go.kr/bsp/wgs/dataView/data300View/91.do). 만 65세 이상 홀로 사는 노인이 대상이고 갱신 주기는 매년이다. 원본의 기준시점은 연도 정밀도로 보존한다. 행정동 자료 포함 여부는 실제 CSV의 강남구 구간에서 검증했다.
- `합계`, `국민기초생활보장 수급권자`, `저소득노인`, `일반`의 4구분과 `계`, `남`, `여`의 3성별을 저장한다. 합계와 세부 항목, 계와 남녀를 중복 합산하지 않는다.
- 이름을 Analysis1의 7자리 행정동 코드에 연결한다. 기존 DB의 개포3동 코드에는 일원2동 명칭도 별칭으로 허용한다. 같은 코드에 두 이름의 행이 중복되거나 새 동이 등장하면 수동 지역 매핑 검토가 필요하다.
- 외부 원본을 바이트 그대로 `Analysis1/data/raw/elderly/<sha256>.csv`에 보관한다. 원본을 수정하거나 누락값을 복원하지 않는다.

## 품질 처리

원본 마지막 줄인 강동구 둔촌2동/일반/여에는 닫는 따옴표가 없다. 허용 설정이 켜져 있고, 강남구 구간이 이미 끝났으며, 단 한 개의 마지막 불완전 레코드인 경우에만 강남구와 무관한 그 레코드를 제외한다. 오류 행·원문·행 번호·파일 해시는 `a1_elder_source.metadata_json`에 기록한다. 강남구 내부 오류, 중간 오류, 다중 오류, 동·구분·성별 누락이나 중복, 불일치 합계는 저장을 차단한다.

2022년 `-` 7개, 2023년 `-` 4개, 2024년 빈칸 1개를 NULL로 유지한다. 완전한 조합에서 남+여=계, 세부 구분 합=합계, 동 합=강남구 총계를 검증한다. 일부 구성값이 NULL이면 검증 불가로 기록하며, 나머지 값의 합이 전체를 넘는 경우는 오류로 처리한다. 총계를 이용해 NULL을 0으로 역산하지 않는다.

## 지표

연간 독거노인 수, 남녀 수와 여성 구성비, 수급권자·저소득·일반 독거노인 수를 제공한다. 경제적 취약성 구성비는 `(수급권자+저소득 독거노인)/전체 독거노인`이다. 이것은 해당 동 모든 고령인구의 빈곤율이나 고립률이 아니다. 구성값이 없거나 분모가 0이면 비율은 NULL이다.

전년 대비 증감은 정확히 직전 연도와 비교한다. 중간 연도가 없거나 직전 합계가 0이면 증감률은 NULL이다. 첫 연도 2022년에는 직전 연도 자료가 없어 비교하지 않는다. 인구 규모나 조사 방식 변화도 수 증가에 영향을 줄 수 있으므로 연간 수 증가를 사회적 고립 악화로 판정하지 않는다.

전체 65세 이상 고령인구 대비 독거노인 비율은 NULL로 둔다. 기존 반기 평균 인구나 통신 추정 인구를 분모로 대체하지 않는다. 앞서 보류한 신규 등록인구 CSV는 사용하지 않았다.

## 연결과 시간·연령 범위

`v_a1_elder_context`는 반기 지역 유형에 가장 최근 완료 가능한 기준 연도를 연결한다. H1은 전년도까지, H2는 같은 연도까지의 관측을 허용하는 사후 맥락이다. 2025H2는 2025년 관측을 연결하지만 2025년 7월에 알려졌던 통계라고 설명하지 않는다.

`v_a123_age_elder_context`는 동·연령·월별 행동·소비 결과에 사건 연도 이하의 가장 최근 연간 통계를 연결한다. **60plus에만 연결하며 만 65세 이상과 60세 이상은 부분적으로 겹친다.** 60~64세 독거노인 수를 포함하거나 연령별 수를 분배하지 않는다. 20~50대 행에는 통계값을 NULL로 두고 `not_applicable_to_age_band`를 표시한다. 모든 동의 고령층 현황은 별도의 연간 조회에서 확인할 수 있다.

`v_a123_age_elder_available_context`는 공표일이 확인됐고 해당 기준 연도가 완료된 통계만 사건 월말까지 연결한다. 소비도 기존 공표일 기준 조회를 사용한다. 현재 독거노인 연도별 실제 공표일은 확인되지 않아 모두 NULL이며, 당시 사용 가능 근거 조회에는 연결되지 않는다. 원본 다운로드 날짜나 웹사이트 전체 갱신일을 각 연도 공표일로 대체하지 않는다.

연간 통계가 여러 월에 나타나도 같은 관측을 반복 참조하는 것이다. 월별 독거노인 증가나 독립적인 여러 근거로 합산하지 않는다. 오래된 연도라도 실제 `elder_year`를 노출하며, 새 연도 미확보 상태를 숨기지 않는다. 독거노인 통계는 사회적 고립 확정 사례 수가 아니다. 동별·연령별 소비 및 통신 자료와 동일 개인을 연결한 자료도 아니다.

## DB 조회

| 조회/테이블 | 단위 및 역할 |
|---|---|
| `a1_elder_source` | 원본 SHA256, 경로, 제외 행, 검산 기록 |
| `a1_elder_year` | 연도별 값 지문, 공표일, 구 합계 |
| `a1_elder_observation` | 동 × 연도 × 구분 × 성별 원 관측값과 문자열 |
| `v_a1_elder_annual` | 동 × 연도 지표와 공표일 |
| `v_a1_elder_context` | 반기 지역 유형과 연간 구조적 맥락 |
| `v_a123_age_elder_context` | 동·연령·월 행동·소비와 고령층 연간 맥락 |
| `v_a123_age_elder_available_context` | 사건 월말 기준 공표일 검증 연결. 소비 분야별 상세 행 |

```sql
SELECT adm_cd,year,
 json_extract(payload_json,'$.elderly_living_alone_total') AS living_alone,
 json_extract(payload_json,'$.economic_vulnerability_share_among_living_alone_elderly') AS economic_share,
 json_extract(payload_json,'$.yoy_count_change_pct') AS annual_count_change_pct
FROM v_a1_elder_annual WHERE year=2025;

SELECT adm_cd,date,age_band,elder_year,elder_age_alignment,
 json_extract(payload_json,'$.communication_signal') AS communication_signal,
 json_extract(elder_context_json,'$.elderly_living_alone_total') AS living_alone
FROM v_a123_age_elder_context WHERE age_band='60plus';
```

## 결과 파일

`outputs/integrated/analysis1_elder_annual.csv`, `analysis1_elder_observations.csv`, `analysis1_elder_context.csv`에 연간 관측과 지역 유형 연결을 저장한다. `analysis123_age_elder_context.csv`는 기존 동·연령별 행동·소비와 연결한 최종 조회이며, `analysis123_age_elder_available_context.csv`는 공표일 기준 상세 결과다. JSON과 펼친 수치를 함께 보존한다.

## 이후 업데이트

1. 같은 구조의 신규 연도 CSV를 원본 폴더에 넣는다. `config/db1_config.json`의 `analysis1.elderly_living_alone.sources`는 현재 파일명의 `F030011_*.csv` 패턴을 검색한다. 다른 파일명이나 위치이면 설정의 경로/패턴을 수정한다.
2. `run_db1.ps1 -Command analysis1-elder`로 독거노인만 갱신하거나, 일반 `scan`/`analysis3` 명령으로 전체 갱신한다. Analysis3의 직접 `scan`/`watch`도 이 자료를 갱신한다. 실제 공표일을 확인했으면 설정의 `available_from`에 `{"2025":"확인한 YYYY-MM-DD"}` 형식으로 기록한다.
3. 입력 기간 전체를 검증하고 새 연도를 추가한 뒤, 연간 지표와 연결 CSV를 갱신한다. 같은 데이터 재실행은 원 관측을 중복 저장하지 않는다. 연도별 값 지문을 비교하므로 기존 연도가 같은 신규 다년 CSV를 추가할 수 있다.
4. 과거 값이 바뀌었거나 여러 CSV가 같은 연도에 다른 값을 주면 자동 덮어쓰기를 차단한다. 원 제공처 정정 여부 확인과 명시적인 버전 이관이 필요하다. 과거 미보유 연도의 뒤늦은 삽입도 기준 이력을 바꿀 수 있어 자동 처리하지 않는다.
5. `export`는 저장된 DB를 읽고 연결 결과를 내보내며 원본 다운로드를 요구하지 않는다. 자동 다운로드·예약 실행은 기존과 마찬가지로 AI agent/서비스 운영 계층의 역할이다.

## 이번 실행

22개 동 × 4년 = 88개 연간 지표, 1,056개 관측 셀을 저장했다. 연령별 월 요약 660행 중 60plus 132행에 연간 맥락을 연결했다. 공표일 기준 상세 조회는 3,300행이며 독거노인 값은 공표일 미확인으로 모두 NULL이다.

강남구 독거노인 합계는 2022년 19,102명, 2023년 20,973명, 2024년 23,747명, 2025년 25,215명이다. 2025년 전년 대비 증감률은 6.18%다. 2025년 수급권자·저소득 독거노인 합계는 6,977명이며 독거노인 중 구성비는 27.67%다.

현재 행동 신호 10건은 30~50대에 발생했다. 따라서 독거노인 자료를 직접 적용할 수 있는 신호는 0건이며, 기존 판정을 바꾸지 않는다. 추가 통계를 넣어 현재 신호의 사회적 고립 설명력이 자동으로 높아졌다고 설명하지 않는다.

검증은 새 독거노인 테스트 13개, 기존 Analysis1 테스트 9개, Analysis3 테스트 33개, DB1 테스트 8개를 통과했다. 연도 추가는 합성 자료로 확인했으며 실제 2026년 독거노인 원본은 아직 없다. 기존 모든 DB 테이블 값, 지역 유형과 행동·소비 판정이 유지되고 SQLite 무결성과 외래키 검증이 통과했다.
