# DB1 근거 보완 결과 (2026-10-07)

기존 탐지·모델·원본 테이블 44개를 보존하면서 설명 근거와 업데이트 경로를 보완했다. 소통 신호 10건, 이동 신호 0건, 복합 신호 0건은 그대로다. 탐지 정확도가 향상됐다는 검증 결과는 아니다.

## 반영한 내용

- 서울시 고립은둔청년 조사: 외출 제한, 장기 지속, 대면 관계, 도움 받을 사람, 대화 상대, 지원 요구 등 세부 통계 476행을 별도 근거로 추가했다. 현재 신호 중 30대 3건에 청년 조사 배경을 연결한다. 동별 개인의 고립을 확정하는 자료는 아니다.
- 가구조사는 가중치와 유효 표본 수를 제공하고 청년조사는 비가중 조사로 표시한다. 20대와 가구조사의 19~29세 범위 차이를 유지하며, 결측·무응답을 정상 응답으로 대체하지 않는다. 지원 요구는 응답한 사람을 분모로 하는 복수 응답 지표다.
- 관측 직전 3개월에 맞춘 기상·달력 근거 48개 창을 추가했다. 2025년 10월 라벨은 7~9월 관측이며 강수량 합계는 954.9mm다. 서울 단위 환경 배경으로 사용한다.
- 소비 자료가 늦게 도착하면 기존 탐지 결과를 보존하고 비어 있던 관련 소비 근거를 보충한다. 변경 전후 내용과 등록 시각을 기록하며 이미 등록된 원본의 변경·삭제는 차단한다.
- AI 조회에 근거별 사용 가능 상태, 표본 제한, 연령·공간·시간 일치 여부를 포함했다. 사용 가능 상태는 위험점수나 신뢰도가 아니다.
- 공개일 등록과 기준일 조회를 추가했다. 공개일이 확인되지 않은 핵심 입력은 기준일 조회에서 제외한다. 현재 통신·관심집단 공개일이 등록되지 않아 기준일 조회 결과는 0건이며, 실시간 성능 검증을 의미하지 않는다.
