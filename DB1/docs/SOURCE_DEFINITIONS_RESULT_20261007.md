# 원천 정의 확인 및 10건 해석 정정

2026-10-07. 기존 공식 소통 10건·이동 0건·결합 0건과 원자료·모델 점수는 유지했다. SNS 음수를 오류로 제외하고 증감률을 계산한 이전 해석은 잘못이었다. 해당 백분율과 8건 품질 부족 판단을 철회한다.

## 확인된 정의

서울시 시민생활 공식 안내와 로컬 매뉴얼 6·7·35쪽을 검토했다. SNS는 공급자 표준화 상대 지수이며 음수는 유효하다. 시점마다 평균·표준편차가 달라 시계열 비교에 부적합하다. 0값 재집계 예정이라는 컬럼 설명서 주석과 일반 FAQ 정의가 충돌해 0을 비사용이나 결측으로 일괄 처리하지 않는다. 재집계 완료 여부는 확인되지 않았다.

집계 기준월은 직전 3개월을 관측한다. 2025-10 기준=7~9월, 2025-11 기준=8~10월이다. 공개 시점은 관측 기간과 별개이며 파일별 실제 공개일은 확인되지 않아 NULL이다. 평일·휴일 지표에서 공휴일 포함 여부도 확인되지 않았다. 이동 자료는 거주 행정동 밖 활동 등 공급자 범위이므로 근거리 외출 전체를 관측하지 않는다.

## 관측 기간에 맞춘 소비 재연결

상권 변화율은 같은 분기 과거 기준 대비이며 동일 개인의 변화가 아니다. 카드의 현재/직전 3개월 완전 비교는 현재 10건 모두 과거 창 자료 부족으로 NULL이다. 이전 10~12월 카드와 Q4 상권 연결은 후속 기간 맥락이며 같은 시점의 동반 변화로 설명하지 않는다. 특히 11월 기준 역삼2동 30대에 Q4 여가 소비 감소를 동반 근거로 제시한 해석을 철회한다.

## 운영 적용과 미확인 항목

새 `v_a123_age_source_context`를 우선 사용한다. 원본 업데이트 후 기존 분석 실행 흐름에 기간 정렬 계산을 연결했다. 기존 같은 기준월 소비 뷰는 보존하고 후속 기간 맥락으로 구분한다. 실제 공개일 미확인으로 새 뷰도 사후 해석용이다.

제공기관에 확인할 질문: SNS 0 재집계 완료 여부와 버전별 처리; 평일/휴일의 법정공휴일 포함 규칙; 파일 기준월과 배포일 정의. 외부 문의를 전송하지 않았으며 답변 전 임의로 보정하지 않는다.
