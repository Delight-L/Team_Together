# v16 경량 구성 (1단계)

이 폴더는 Team Together 메인 대시보드에서 사용하는 v16 경량 구성입니다.

## 포함된 항목

- `chatbot_agent`: v16 질문 해석 및 답변 코드
- `DB1`: 분석 코드와 현재 사용하는 모델·참조자료
- `data_pipeline`, `backend`, `config`: v16 실행에 필요한 코드
- `outputs/db1.sqlite`: 현재 활성 스냅샷을 복사한 읽기용 SQLite 데이터베이스

## 이번 단계의 범위

- 메인 화면의 `/api/chat` → 총괄 에이전트 → `../v16_service.py`를 통해 호출합니다.
- 원본 v16 폴더의 파일은 수정하지 않았습니다.
- v16 프론트엔드, 가상환경, 과거 스냅샷·백업, 원시 대용량 자료는 복사하지 않았습니다.
- 메인 프론트엔드를 사용하고, 복지사업·보고서 질문은 총괄이 기존 담당에게 전달합니다.
- Gemini가 조회 의도를 판단하며, 답변은 v16의 검증된 DB 근거와 출력 형식으로 작성합니다.
- 이상신호 소개·이유·연령별 활동 변화는 쉬운 설명문으로 작성합니다. Gemini 연결 여부와 관계없이 같은 문장 형식을 사용합니다. 기본 소개에는 같은 동·같은 기준월의 연령별 변화와 실제 연령별 신호 여부를 함께 보여줍니다.
