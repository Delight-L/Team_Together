# 지역 변화 신호 설명 기준

이 문서는 조회된 수치를 공무원이 이해하기 쉬운 말로 설명하기 위한 근거 문서다.
수치를 바꾸거나 새로운 사실을 추가하지 않는다.

## 이동 신호

- 이동 신호는 평일 이동과 휴일 이동 변화가 함께 기준을 충족한 경우다.
- 각 Robust Z 수치와 함께 “그 동의 과거 월별 변화와 비교해 이례적으로 낮았다”는 뜻을 짧게 설명한다.
- 두 이동 수치가 함께 낮으면 “한 지표만의 일시적 변동으로 보기보다, 평일·휴일 이동 변화를 함께 확인할 필요가 있다”고 설명할 수 있다.

## 통신 신호

- 통신 신호는 통화 상대 수와 문자 상대 수 변화가 함께 기준을 충족한 경우다.
- 각 Robust Z 수치와 함께 “그 동의 과거 월별 변화와 비교해 이례적으로 낮았다”는 뜻을 짧게 설명한다.
- 통화 또는 문자 한쪽이 직접 근거가 아니면, 이번 신호의 핵심 근거가 아니라고 구분한다.

## Robust Z 설명

- Robust Z는 해당 동의 과거 월별 변화와 비교한 이례성 정도다.
- 값이 더 낮을수록 평소 변화 범위에서 더 벗어난 감소를 뜻한다.
- 수치가 확인된 경우에는 반드시 원값을 함께 제시한다.

## 보조 정보

- 강수일·강수량·적설일·이동거리·관심집단·지역유형은 신호를 판정한 직접 기준이 아니다.
- 보조 정보는 “당시 상황 또는 현장 확인 시 참고할 정보”로만 표현한다.
- 보조 정보만으로 감소 원인을 확정하지 않는다.

## 출력 원칙

- 답변은 한 줄 결론, `확인 수치 | 쉬운 설명`, 현장 확인 방향 순서로 작성한다.
- 개인의 사회적 고립 여부나 특정 원인을 단정하지 않는다.
- 모든 답변에 같은 주의 문구를 반복하지 않는다.
