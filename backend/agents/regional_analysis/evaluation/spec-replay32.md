## Intent
사용자가 승인한 범위: 기본 질문 32개로 축소하고 평가 실행 오류를 수정한 뒤 재평가한다.
기존 실행기는 steps와 화면 선택을 소실하고 예상 정답 범위를 입력으로 사용했다.
원본의 B01~B32와 근거를 보존하고 실제 응답을 다음 입력에 전달한다.

## Boundaries
기존 휴먼 리뷰와 이전 결과는 보존한다. 데이터베이스나 챗봇을 점수 향상을 위해 수정하지 않는다.
메인 서비스 대화 평가와 v16 대시보드 구성요소 평가는 구분한다. 웹 UI 통합 검증이라고 주장하지 않는다.
모범답안은 실제 답변에서 역생성하지 않는다. DB 내용 검증과 사람 승인 상태를 구분한다.

- [ ] datasets/v16_questions_32.jsonl: 원본 steps, references, expected_behavior와 금지조건 보존; 4경로 각 8개.
- [ ] 데이터 근거 전체 논리 비교 및 차이 보고; 다른 파일 해시를 동일 내용이라고 단정하지 않기.
- [ ] run_eval.py: 실제 이력 순차 전달, 선택 자동 설명 호출, 연령 범위, 선택 변경 초기화, 케이스 독립성.
- [ ] 실패 단계와 미평가 기록, expected_scope 입력 누출 금지, DB 해시 불일치 차단.
- [ ] BLEU1 길이 벌점 및 ROUGE F1 명시; 기존 잘못된 점수와 비교 금지.
- [ ] 의미 있는 회귀 테스트와 32개 재실행.
- [ ] 32개 답변 직접 검토 및 판정 근거 보고서.

Given 후속 질문, when 실행, then 앞선 실제 답변이 함께 전달된다.
Given 화면 선택, when 실행, then 선택한 동·월·연령으로 자동 설명하며 요약 질문으로 대체하지 않는다.
Given DB 불일치 또는 선행 실행 실패, when 채점, then 정상 점수로 합산하지 않는다.
Given 기존 사용자 리뷰, when 신규 평가 저장, then 원본은 변경하지 않는다.
