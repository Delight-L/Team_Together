# 과거 SQLite 평가 실행기

이 폴더는 2026-10-14~15 평가를 만들던 실행 코드의 보관본입니다.
현재 보미·PostgreSQL 서비스용 실행 명령으로 사용하지 않습니다.

| 파일 | 보관 이유 |
|---|---|
| `run_eval.py` | 제거된 `v16_service`, `DataRepository`, `backend.app`를 호출하던 순차 평가 실행기 |
| `prepare_dataset32.py` | 개발자 PC의 별도 원본 폴더와 SQLite 스냅샷을 비교하던 준비 도구 |
| `import_dataset.py` | 단계 누락·해시 변경 문제 때문에 이미 사용 중지된 가져오기 도구 |

원본과 비교할 수 있도록 코드와 과거 데이터·결과는 보존했습니다. 상대 경로 역시 당시 코드 그대로이므로
이 위치에서 실행해 현재 서비스를 평가할 수 없습니다. 현재 가능한 검사는 [평가 안내](../README.md)를 보세요.
