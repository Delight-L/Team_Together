현재 DB1 결과와 AI agent 담당자 인계 자료를 정리한 브랜치입니다.

| 위치 | 내용 |
|---|---|
| [DB1](DB1/README.md) | 최신 전처리·분석·업데이트 파이프라인과 통합 DB |
| [AI agent 인계 안내](DB1/docs/AI_AGENT_HANDOFF.md) | 데이터 구조, 읽기 전용 조회 예제, 해석 기준, 담당 범위 |
| [수정 전 DB1](archive/DB1_before_20261006/README.md) | 이전 브랜치의 DB1 및 DB1.zip 원본 보관 |
| agent/ | 기존 팀원 agent 코드. 이번 DB1 업데이트에서 수정하지 않음 |
| 서울시 공공데이터/ | 기존 노트북 자료. 원래 위치 유지 |

DB1 운영 기준은 `DB1/outputs/db1.sqlite`입니다. 통합 요약은 22개 동 × 2025년 7~12월의 132행, 상세는 3,960행입니다. 로컬 Desktop DB1의 전체 58개 검증이 통과했으며 저장소로 복사한 DB 무결성도 확인했습니다. 읽기 전용 Python·SQL 예제는 인계 문서를 참조하세요.

조회만 하는 팀원은 SQLite DB와 인계 안내서부터 사용하면 됩니다. 다른 PC에서 업데이트를 실행하려면 원본 자료 위치, 설정 JSON의 절대 경로, Python 환경을 준비해야 합니다. 원본 전체 자료와 로컬 백업 ZIP은 이번 전달본에 새로 추가하지 않았습니다. DB와 테스트 예제, 기준 자료 및 분석 출력은 포함합니다.

기존 agent와 최신 DB1의 서비스 연결은 AI agent 담당자의 후속 작업입니다. 이번 전달로 자동 연동됐다는 의미는 아닙니다. 신규 데이터에 따라 결과 수치가 바뀔 수 있으며 현재 CSV·그래프는 저장 시점의 결과입니다.
