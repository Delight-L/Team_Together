# 화면 디자인 규칙

모든 탭이 같은 앱처럼 보이도록 색·글자·모양의 기준을 정합니다.
색감은 **종합 현황**을 기준으로 삼았고, 값은 `frontend/src/style.css`의 `:root`에 공통 값(CSS 변수)으로 정의되어 있습니다.

## 적용 범위

| 화면 | 적용 |
|---|---|
| 지역 현황 · 지역 분석 · 사업 매칭 검토 · 보고서 작성 · 관리 화면 · 보미 채팅 | 이 규칙을 따릅니다. |
| 종합 현황(폴더 화면) | **이번에는 제외**합니다. 폴더 배치와 글자 크기를 그대로 둡니다. 공용 규칙이 바뀌어도 이전 값을 유지하도록 `style.css` 끝에 보존 규칙(`.group-shell ...`)을 두었습니다. |
| 사이드바 · 상단바(모든 화면 공용 틀) | 이 규칙을 따릅니다. |

## 1. 색

새 색 코드를 직접 쓰지 말고 아래 변수를 쓰세요. 맞는 값이 없으면 변수를 먼저 추가하고 이 표에 적습니다.

| 변수 | 값 | 용도 |
|---|---|---|
| `--blue` | `#2563eb` | 주색: 주요 버튼, 선택 상태, 링크 |
| `--blue-strong` | `#1d4ed8` | 주색 강조(눌림·진한 링크) |
| `--text-strong` | `#12213e` | 제목 |
| `--text` | `#20304d` | 본문 |
| `--text-sub` | `#4b6488` | 보조 설명, 표 내용 |
| `--text-muted` | `#71829e` | 흐린 글자: 날짜, 출처, 표 머리글 |
| `--text-faint` | `#8798b3` | 가장 흐린 글자: 입력 예시, 비활성. 본문에는 쓰지 않습니다. |
| `--line` | `#dce8fa` | 기본 테두리·구분선 |
| `--line-strong` | `#c8dcfa` | 강조 테두리(선택된 카드 등) |
| `--surface` | `#ffffff` | 카드 바탕 |
| `--surface-soft` | `#f7fbff` | 카드 안 영역, 표 머리글 바탕 |
| `--surface-tint` | `#f0f6ff` | 연한 파랑 강조 바탕(선택·안내) |
| `--page` | `#f4f7fc` | 화면 바탕 |

## 2. 상태 표시

**같은 뜻은 모든 화면에서 같은 색**을 씁니다. 상태 표시는 `status-tag` 클래스를 씁니다.

| 뜻 | 화면 글자 예 | 클래스 | 변수 |
|---|---|---|---|
| 후보 | 신규 후보, 변화 후보, 확인 후보 | `status-tag rose` | `--status-candidate`, `--status-candidate-bg` |
| 연속 | 연속 후보 | `status-tag orange` | `--status-continuing`, `--status-continuing-bg` |
| 보류·확인 필요 | 판단 보류, 이력 부족 | `status-tag sky` | `--status-pending`, `--status-pending-bg` |
| 해당 없음 | 기준 미해당 | `status-tag` | `--status-quiet`, `--status-quiet-bg` |
| AI가 만든 내용 | AI 답변 | `bomi-badge ai` | `--status-ai`, `--status-ai-bg` |
| 자료로 만든 내용 | 자료 기반 | `bomi-badge data` | `--status-pending`, `--status-pending-bg` |

## 3. 글자 크기

- 최소 **11px**. 이보다 작은 글자는 쓰지 않습니다(업무 화면에서 읽기 어렵고 접근성 기준에 맞지 않음).
- 단계: **11 / 12 / 13 / 15 / 18 / 24px**, 페이지 큰 제목만 28px까지.
- 종합 현황은 한 화면 배치 때문에 9~10px 글자가 남아 있습니다. 바꾸려면 배치 조정과 함께 따로 진행합니다.

## 4. 모양

| 변수 | 값 | 용도 |
|---|---|---|
| `--radius-sm` | 8px | 버튼, 입력칸, 작은 상자 |
| `--radius` | 12px | 카드 |
| `--radius-pill` | 999px | 배지, 스위치 |

## 5. 새 화면을 만들 때

1. 색·모서리는 위 변수만 씁니다.
2. 상태는 2번 표의 클래스를 그대로 씁니다. 새 상태가 필요하면 표에 먼저 추가합니다.
3. 글자는 11px 이상, 3번의 단계 중에서 고릅니다.
4. 종합 현황 전용 스타일(`.group-shell`, `.briefing-shell`, `.gd-`)은 다른 화면에서 쓰지 않습니다.

## 남은 일

- 기존 CSS의 모서리 값(26종)은 아직 변수로 정리하지 않았습니다. 화면을 고칠 때 함께 바꿉니다.
- 따뜻한 색(노랑·주황 배경 등)과 진한 강조색 일부는 화면별 의미가 달라 자동 정리에서 제외했습니다.
- `case-briefing.css`의 사건 파일 관련 규칙 상당수는 현재 화면에서 쓰지 않는 코드입니다. 정리 대상입니다.
