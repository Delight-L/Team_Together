# 메뉴 고도화 1단계: 업무와 그룹 관찰의 연결안

상태: 그룹 연결안(1단계)은 보류. 사용자가 진행 순서의 2단계(작은 오류·상태 표시)와 6단계(지역 현황·관리 메뉴·보미 개선)를 먼저 선택함.

## 먼저 반영한 개선

### 3·4·5단계 추가 반영 (2026-10-15)

현재 카드·색상·메뉴·표 배치를 유지하며 아래 내용을 확장함. 그룹 연결안은 계속 보류.

- 지역 분석: 실제 후보 지표 요약, 수치 설명, 저장 당시/현재 근거 비교, 기존 업무 기록과 같은 저장본을 쓰는 접이식 검토 의견 입력.
- 사업 검토: 기존 후보 목록에서 지원 목적 관련어 필터, 이용 조건 체크리스트와 목적 저장, 사업별 최신 판단/이전 이력 분리. 다른 지역 참고 사례의 저장 제한은 유지.
- 보고서: 저장한 후보 지표·사업 선택, 업무 기록의 의견·담당자·기한·후속 조치 선택 반영, 작성 화면의 근거 대조, 갱신 전 편집본 보관.
- 새 체크리스트·목적은 기존 검토 JSON에 저장하므로 새 테이블 이관은 필요하지 않음. 기록이 없는 이전 검토는 미확인 상태로 표시.
- 선택 항목과 업무 기록 버전을 서버에서 확인하며, 선택하지 않은 분석·사업 상세는 기본 초안에서 제외. 업무 기록이 초안 생성 뒤 바뀌면 파일 생성 전에 갱신을 안내.
- 검증: 임시 업무 저장소 기반 API·Word 회귀 검사, 실제 DB 자료의 화면 확인, 별도 소유자의 PostgreSQL 임시 기록으로 저장→재조회→보고서 파일 저장·다운로드 확인 후 생성한 행만 정리.

### 2·6단계

- 지역 현황의 후보·이력 부족·자료 없음 요약, 검색 조건 초기화, 좁은 화면 표·지도 세로 배치.
- 목록과 분석 초기 선택의 후보 정렬 일치, 비교 지역 추가 문구 치환.
- 업무 목록 재조회와 보고서 저장 완료 표시. 후속 조치 완료와 혼동하지 않도록 구분.
- 활동 이력 검색·종류 필터·최신순 정렬·재조회와 로딩/빈 결과/실패 구분.
- 업로드 종류 변경 시 파일 초기화, 선택 파일·용량·검사 유효시간·반영 버전 안내, 반영 후 앱 자료 재조회.
- AI 설정의 저장/미저장 상태 구분, 저장된 설정의 연결 확인, 키 유지·환경설정 우선순위 안내.
- 보고서 목록 조회 실패와 재시도, AI 사용 가능 여부 설정 변경 반영.
- 보미의 질문 대상·메뉴별 예시 질문, 전송 전 질문 편집, 설정 조회 복구와 실패 질문 재시도.

검증: 실제 DB 지역 현황·활동 이력 조회, 좁은 화면 가로 넘침 확인, 별도 검증 서버의 업로드 반영 후 자료 버전 재조회와 실패 재시도. 검증 서버는 실제 DB와 외부 AI를 호출하지 않는다. 운영 DB에 시험 자료를 반영하지 않음.

## 현재 확인한 구조

- 동별 업무와 보고서는 담당자·시군구·동·기준월로 저장한다.
- 그룹 메모는 담당자·시군구·행정구역 코드·기준월·연령·성별로 별도 저장한다.
- 검토·후속 조치는 시군구·동·기준월 기준으로 같은 지역 담당자가 공유한다.
- 메인에서 지역 분석으로 이동할 때 지역과 월만 전달되며 그룹 선택은 이어지지 않는다.
- 그룹 유동량과 동 전체 통화·문자·이동 분석은 서로 다른 근거다. 춘천 그룹 자료가 있다는 사실이 동별 분석 자료의 제공을 뜻하지 않는다.

## 제안하는 기준

동별 업무 한 건에 여러 그룹 관찰 기록을 연결한다. 그룹을 선택한 채 이동하는 것은 화면 맥락 전달이며, 업무 저장이나 근거 검토 완료를 자동으로 수행하지 않는다.

1. 화면 맥락: 시군구·행정구역 코드·표시 이름·월과 선택 그룹의 연령·성별을 전달한다. 지역 또는 월이 바뀌면 맞지 않는 그룹 선택은 해제한다.
2. 그룹 연결: 담당자가 저장한 그룹 메모를 선택하여 업무에 연결한다. 연결할 때 그룹 식별값, 메모, 지원 목적, 저장 시각, 원자료 버전과 필요한 관찰 수치·단위·비교 기준을 서버 조회값으로 보관한다.
3. 근거 구분: 그룹 유동량, 동 전체 분석, 연간 지역 배경을 별도 영역으로 표시한다. 그룹 변화는 동 전체 후보 판정이나 개인 자격으로 환산하지 않는다.
4. 버전 보존: 연결 당시 근거를 보존한다. 원본 메모 또는 자료가 변경되면 안내하고 담당자가 갱신하도록 한다. 분석 재시작 시 기존 연결은 이전 회차로 보관하고 다시 확인하여 연결한다.
5. 접근 범위: 최초에는 본인이 저장한 그룹 메모만 자신의 업무에 연결한다. 기존 지역 공유 기록에 개인 그룹 메모를 자동 공개하지 않는다. 공유 기록이나 보고서에 포함할 내용은 담당자가 직접 선택한다.
6. 자료 미제공: 동별 분석이 없는 지역은 그룹 조회·메모를 유지하되 동별 업무 단계와 보고서 생성을 완료한 것처럼 표시하지 않는다. 그룹만으로 시작하는 별도 업무 흐름은 후속 범위로 둔다.

## 메뉴별 연결 결과

| 메뉴 | 연결 후 표시·행동 |
|---|---|
| 종합 현황 | 선택 그룹을 지역 분석으로 전달. 기존 관찰 화면 배치 유지 |
| 지역 현황 | 전체 지역 탐색. 그룹별 목록으로 변경하지 않음 |
| 지역 분석 | 선택 그룹 관찰 요약과 동 전체 근거를 구분. 저장한 그룹 메모를 업무에 연결 |
| 사업 매칭 검토 | 연결한 관찰의 지원 목적을 검색 조건으로 사용. 여러 목적은 선택하여 검색하고 이용 자격은 별도 확인 |
| 업무 기록 | 업무에 연결한 그룹과 메모를 확인. 지역 공유 후속 조치와 구분 |
| 보고서 작성 | 포함할 그룹 관찰을 선택. 그룹·동·연간 자료의 단위와 출처를 구분 |
| 보미 | 선택 그룹과 동 전체 중 질문 대상을 표시하고 해당 근거로 응답 |

## 구현 순서와 완료 기준

1. 이 연결 기준을 확정한다.
2. 작은 오류와 로딩·빈 결과·실패 상태를 수정한다.
3. 지역 분석에서 맥락 전달과 연결 저장을 구현한다.
4. 사업 매칭 검토에 지원 목적을 연결한다.
5. 업무 기록과 보고서에서 저장한 연결을 조회·선택한다.
6. 지역 현황·관리 메뉴·보미를 개선한다.

완료 확인: 그룹 선택 후 이동 시 대상 유지, 다른 지역·월 선택 시 오래된 선택 해제, 저장 후 재접속 복원, 다른 담당자 기록 접근 제한, 원자료 변경 안내, 보고서 근거 구분, 실제 API와 PostgreSQL 저장 확인.

구현 전 해당 변경 범위의 기존 로컬 수정과 충돌 여부를 확인한다. 주요 UI 변경은 기존 디자인 규칙을 따르고 실제 브라우저에서 확인한다.
