지역 분석 agent가 답하는 사용자 질문 유형

※ 질문은 크게 3가지로 나눌 수 있습니다.
   1) 화면에 보이는 내용을 이해하는 질문
   2) 화면에 없는 변화나 맥락을 더 알아보는 질문
   3) 자료의 출처와 근거를 확인하는 질문


1. 화면에 있는 정보 질문

1-1. 화면 요약

• 현재 화면에서 가장 중요한 내용만 짧고 쉽게 정리합니다.
• 선택한 지역·동네, 기준월, 연령대가 무엇인지 먼저 알려줍니다.
• 현재 탐지 상태와 통신·이동 지표의 방향을 함께 설명합니다.
• 숫자를 그대로 나열하지 않고 “무엇이 늘었고 무엇이 줄었는지”를 말합니다.
• 화면에 없는 내용을 추측하지 않고, 화면에서 확인되는 범위만 답합니다.

질문 예시
• “지금 화면을 쉽게 요약해 줘.”
• “이 화면에서 가장 중요한 내용이 뭐야?”
• “현재 선택된 지역과 연령대가 어디야?”

답변 예시 방향
• “현재 강남구 신사동 30대의 2025년 11월 변화 화면입니다.”
• “전화 연락은 줄었지만 평일 이동은 비슷하게 나타납니다.”
• “이 결과는 지역·연령대별 집계이며, 개인 한 명의 상태를 뜻하지 않습니다.”


1-2. 이상신호 탐지 이유

• 왜 ‘탐지’, ‘후보’, ‘확인 대상’으로 표시되었는지 설명합니다.
• 전화 연락·문자 연락·평일 이동·휴일 이동 중 어떤 지표가 기준과 달라졌는지 알려줍니다.
• 자료가 충분했는지, 과거와 비교할 수 있었는지도 함께 설명합니다.
• ‘신호가 보였다’와 ‘원인이 밝혀졌다’를 구분합니다.
• 탐지는 추가로 살펴볼 지역을 찾는 표시이지, 개인의 고립이나 복지 필요를 확정하는 진단이 아니라고 안내합니다.

질문 예시
• “왜 이상신호가 탐지됐어?”
• “이 지역이 후보로 표시된 이유가 뭐야?”
• “통신 감소 탐지는 무슨 뜻이야?”
• “판정 가능·미탐지는 어떤 상태야?”

답변에 포함할 내용
• 어떤 지표가 변했는지
• 비교 기준이 무엇인지
• 자료가 충분했는지
• 아직 알 수 없는 부분이 무엇인지


1-3. 화면 안 기능·지표 설명

• 화면에 보이는 버튼, 카드, 그래프, 탭의 역할을 설명합니다.
• “이 기능은 무엇을 보여주는가?”를 먼저 말하고, 숫자를 읽는 방법을 이어서 설명합니다.
• 통신 지표와 이동 지표를 구분합니다.
  - 전화 연락: 전화로 연락한 상대 수의 변화
  - 문자 연락: 문자로 연락한 상대 수의 변화
  - 평일 이동: 월요일부터 금요일까지의 이동 활동 변화
  - 휴일 이동: 토·일요일과 공휴일의 이동 활동 변화
• 그래프의 100은 탐지 직전 달을 기준으로 삼았다는 뜻입니다.
• +5%는 기준보다 약 5% 높고, -5%는 기준보다 약 5% 낮다는 뜻입니다.
• 실제 활동량·계절성 고려·강남구 흐름 고려가 무엇인지 구분해 설명합니다.
  - 실제 활동량: 다른 보정을 하지 않은 원래 변화
  - 계절성 고려: 방학·명절처럼 매년 반복되는 영향까지 생각한 비교
  - 강남구 흐름 고려: 강남구 전체가 함께 움직인 부분을 빼고 선택한 동의 변화를 보는 비교
• 가구 구성, 독거노인 비율, 사회적 연결 지표는 지역 배경을 보여주는 참고 자료라고 설명합니다.

질문 예시
• “평일 이동 -6%는 무슨 뜻이야?”
• “강남구 흐름 고려가 뭐야?”
• “자료 확인 탭은 어떤 기능이야?”
• “유효 비율 80%는 무슨 뜻이야?”


2. 화면에 없는 정보 질문

2-1. 이후 변화 추이 확인

• 탐지된 달 이후에 지표가 계속 줄었는지, 다시 올라왔는지 확인합니다.
• 한 달의 변화인지, 여러 달 이어진 변화인지 구분해 설명합니다.
• 전화·문자·평일 이동·휴일 이동을 각각 나누어 보여줍니다.
• 탐지 이후 변화가 좋아졌다고 해서 원인이 해결됐다고 단정하지 않습니다.
• 이후 자료가 없거나 비교할 수 없으면 “확인할 자료가 부족하다”고 분명히 말합니다.

질문 예시
• “탐지된 이후에는 어떻게 변했어?”
• “이후에도 계속 감소했어?”
• “다시 평소 수준으로 돌아왔어?”

답변에 포함할 내용
• 탐지 이후의 기간
• 지표별 방향과 변화 폭
• 변화가 이어졌는지 여부
• 비교할 수 없는 달이 있는지 여부


2-2. 소비·날씨 등 보조 맥락 설명

• 통신·이동 변화와 함께 볼 수 있는 주변 상황을 소개합니다.
• 소비 자료는 선택한 동에 있는 상점의 결제건수 변화이며, 주민 개인의 소비액이 아닙니다.
• 외식·카페, 여가·운동, 생활서비스, 생활필수, 의료·건강 등 분야별 변화를 설명합니다.
• 날씨·계절·방학·명절 같은 상황이 있었는지 참고로 설명합니다.
• 보조 정보는 변화의 가능한 배경을 살펴보는 자료이지, 원인을 확정하는 증거가 아닙니다.
• 소비나 날씨만으로 통신·이동 변화의 원인을 단정하지 않습니다.

질문 예시
• “소비 변화와 같이 보면 어때?”
• “날씨나 계절의 영향이 있었을까?”
• “어떤 소비 분야가 가장 많이 변했어?”


2-3. 추가 확인 자료 안내

• 현재 화면에 없는 자료 중 추가로 확인할 만한 것을 알려줍니다.
• 월별 추이, 다른 연령대, 다른 지역, 소비 분야, 사회적 연결 설문 등을 안내할 수 있습니다.
• 자료가 실제로 연결되어 있는지 먼저 확인하고, 없는 자료는 있는 것처럼 말하지 않습니다.
• 추가 자료를 보더라도 개인을 특정하거나 복지 자격을 자동으로 판단하지 않습니다.
• 마지막에는 사용자가 다음에 무엇을 보면 좋을지 한 가지 정도 제안합니다.

질문 예시
• “추가로 볼 자료가 있어?”
• “다른 연령대와 비교할 수 있어?”
• “이 지역을 더 확인하려면 무엇을 봐야 해?”


3. 자료 근거·출처 확인 질문

3-1. 원본 데이터 출처 확인

• 화면의 숫자가 어떤 자료에서 왔는지 설명합니다.
• 통화·문자·이동 자료, 유동인구 자료, 가구 구성 자료, 설문 자료를 서로 구분합니다.
• 서울서베이 같은 설문 자료는 주민이 응답한 지역·연령대별 통계라고 설명합니다.
• 자료가 개인의 원본 기록인지, 여러 사람의 자료를 모은 지역 통계인지 구분합니다.
• 확인되지 않은 파일명이나 링크는 만들어 내지 않습니다.

질문 예시
• “이 지표의 원본 데이터는 뭐야?”
• “어디에서 가져온 자료야?”
• “가구·관계망 자료와 통신 자료는 같은 출처야?”


3-2. 자료를 모으고 비교한 기준 확인

• 어느 지역·달·연령대의 자료인지 설명합니다.
• 지난달 비교인지, 과거 같은 달 비교인지, 강남구 전체와 비교인지 구분합니다.
• 자료가 부족하면 계산하지 않고 “비교 불가”로 표시한다는 점을 알려줍니다.
• 유효 비율과 판정 기준이 무엇인지 쉽게 설명합니다.
• 숫자를 계산한 기준과 탐지 기준은 다를 수 있으므로 각각 따로 설명합니다.

질문 예시
• “이 퍼센트는 어떤 기준으로 계산했어?”
• “왜 전월 변화량을 계산할 수 없어?”
• “판정 기준 80%는 무슨 뜻이야?”


3-3. 자료의 한계와 해석 범위

• 화면의 결과는 지역·연령대 집계 자료라는 점을 먼저 밝힙니다.
• 실제 사람 수, 개인의 연락 여부, 개인의 외출 여부와 같지 않다고 설명합니다.
• 탐지 결과만으로 고립·복지 필요·변화 원인을 확정할 수 없다고 안내합니다.
• 필요하면 현장 확인이나 담당자 검토가 추가로 필요하다고 말합니다.
• 사용자가 원하는 답을 억지로 만들지 않고, 자료로 알 수 있는 것과 알 수 없는 것을 나누어 답합니다.
