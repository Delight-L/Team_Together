# 2026-10-06 대시보드와 폴더 정리

main 기준의 중복 병합 코드를 복구하고 기존 hyungwoo 브랜치에 커밋된 분석 연결과 화면 복구를 적용했습니다. 원래 작업 폴더의 미커밋 수정은 보존합니다.

구조를 chatbot / agents / dashboard / preprocessing / db / ci로 분리했습니다. 분석 데이터·설정·참조자료·테스트 fixture는 경로를 갱신하여 보존했습니다. `agent(쓰지않음)`, 중복 챗봇 테스트, Git에 잘못 포함된 pyc와 사용하지 않는 이전 HTML·네이티브 화면 초안을 제거했습니다. 삭제된 원본은 main의 Git 이력에서 복구할 수 있습니다. 원천 데이터는 삭제하지 않았습니다.

기존 경로는 변경되었습니다. 루트 main.py로 실행하면 새 경로를 사용합니다. 기존 환경의 .env는 루트에 유지합니다. SQLite 기록은 첫 사용 시 db/runtime으로 복사 이관하며 원본은 보존합니다.

CI 화면에는 제공된 투명 이미지와 가이드 팔레트를 사용합니다. 지도 경계는 기존 JSON을 재사용하며 높이는 장식입니다. 메뉴 선택과 기본 답변은 토큰을 사용하지 않으며 명시적인 AI 모드 질문에만 API 호출을 허용합니다.

## 검증 완료

- 챗봇 호출 조건 3개, 데이터 챗봇 9개, 업무 저장·대화상자 6개, 전처리 10개 테스트 통과
- 대시보드 계산 40,420건과 JavaScript 컴포넌트 구문·업무 흐름 통과
- Analysis2 출력이 기존 참조 결과와 일치하며 네트워크 없이 전체 전처리→분석 파이프라인 실행 성공
- 독립 챗봇 AppTest와 브라우저에서 주제 선택·키보드 지역 강조·상세 분석 전환 확인
- 실제 Gemini 요청과 외부 PostgreSQL 쓰기는 실행하지 않음

구형 가상 챗봇과 사용하지 않는 원본 병합 스크립트, 충돌하는 하위 requirements를 제거했습니다. 의존성 설치는 루트 requirements.txt로 통일합니다.


## 추가 개선: README 원본·보미 로그인·지역 상세 팝업

- 초기 main README의 프로젝트 설명, 전체 아키텍처, Agent 흐름도를 복원하고 현재 코드 구조·구현 현황을 반영했습니다. 목표 설계와 현재 실행 경로를 구분했습니다.
- dashboard 루트 Python 파일 17개를 5개로 정리했습니다. 설정·자료 검사·근거 선택은 common.py, 대화상자는 dialogs.py로 통합했습니다. DB 업무 기록과 시연 자료는 db, 오프라인 검증 도구는 dashboard/tools로 이관했습니다.
- 로그인에 원본 보미 이미지와 CI 컬러를 적용했습니다.
- 종합 브리핑: 신규·연속 후보 및 이력 보류 카드, 지도, 월별 변화, 도우미. 지역 현황: 넓은 지도와 실제 후보 지역 카드.
- 지도 클릭·Enter/Space는 상세 팝업만 엽니다. 팝업에는 변화율·상대 변화·Robust Z·판정을 표시합니다. 업무 시작 버튼부터 기존 업무 기록 흐름으로 연결합니다. Escape 및 닫기 버튼을 지원합니다.
- 참조 이미지의 예시 수치와 지역 순위를 복제하지 않고 실제 선택 월 결과를 사용했습니다. 경계 경로를 보존하며 높이는 장식입니다.
- 검증: 계산 40,420개·JS 문법/업무 흐름, SQLite 기록 및 Word 보고서 AppTest, 실제 브라우저 클릭·키보드 팝업 검증.
