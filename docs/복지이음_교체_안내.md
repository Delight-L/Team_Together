# 복지이음 챗봇

chat_test2/backend/app의 코드 파일을 Team_Together/chatbot/welfare/app으로 가져오고, 팀 채팅이 원본의 handle_chat을 호출하도록 연결했습니다.
기존 로그인 세션과 지역 선택을 사용하며 Python 서버(8503) 한 개로 화면과 API를 제공합니다.
chat_test2의 5174/8001 서버는 실행할 필요가 없습니다.

## 실행과 설정

`run_dashboard.cmd`를 실행하고 http://127.0.0.1:8503 에서 로그인하세요.
복지이음 메뉴 또는 오른쪽 채팅 패널에서 질문할 수 있습니다.

API 키 없이도 팀 자료 검색과 출처 안내가 동작합니다.
AI 답변은 프로젝트 루트 `.env`에 다음을 입력하고 서버를 재시작하면 사용할 수 있습니다.

```env
OPENAI_API_KEY=발급받은_키
OPENAI_MODEL=gpt-4o-mini
```

기존 DB 설정이 있는 `.env`는 유지하고 위 두 항목만 추가하세요.
이번 이식에서 chat_test2/backend/.env의 OpenAI 키·모델을 팀 루트 .env의 비어 있는 항목에 이어받았습니다. 기존 팀 설정이 있으면 그 값을 우선합니다. 실제 키 값은 출력하거나 문서에 넣지 않습니다.
AI 모드에서 예시 질문과 자유 질문 모두 대화와 검색 자료를 OpenAI에 전송합니다.
키는 브라우저나 저장소에 포함하지 마세요. AI 호출에 실패하면 자료 안내로 전환합니다.

## 구현 위치

- `chatbot/welfare/app/agent/resources.py`: chat_test2에서 가져온 자료 읽기와 검색. 서울·강남 외 지역은 자료 범위 부족을 안내합니다.
- `chatbot/welfare/data/`: 복지사업 자료 사본. 실제 사업 DB와 자동 동기화하지 않습니다.
- `chatbot/welfare/app/config.py`, `schemas.py`: 원본의 설정과 메시지 형식.
- `chatbot/welfare/app/agent/orchestrator.py`: 원본 handle_chat. 검색 자료, 안내 규칙, AI/로컬 답변을 담당합니다.
- `chatbot/welfare/app/llm/openai_client.py`: 원본 AsyncOpenAI 스트리밍 클라이언트. 팀 서버의 요청별 루프에 맞춰 생성·종료합니다.
- `chatbot/welfare/service.py`: 팀 HTTP 서버와 원본 비동기 함수를 연결합니다. 별도 검색·프롬프트·OpenAI 호출 구현은 제거했습니다.
- `chatbot/orchestrator.py`: 기존 JSON 대화 호출자를 복지이음으로 연결합니다.
- `webapp/server.py`: 로그인/지역 검사와 `/api/chat` JSON 또는 SSE 응답, `/api/chat/config` 모드 표시.
- `frontend/src/components.jsx`: 복지이음 화면, 출처 표시, 새 대화, 응답 중지.
- `frontend/src/api.js`: SSE 파서.

원본 파일별 이식 위치와 변경 사유는 [코드 이식 안내](../chatbot/welfare/README.md)를 확인하세요.

선택한 지역은 검색 맥락입니다. 기준월은 지역 분석의 기준으로 사업 연도나 운영 시점을 의미하지 않습니다.
지역·월 변경 시 진행 중 요청을 취소하고 대화를 초기화합니다. 대화는 화면 메모리에 보관합니다.

## 자료 기준

policy_candidates.json은 검토일 2026-10-06의 후보 자료,
gangnam_policy_plans_2025.json은 2025년 계획입니다.
현재 모집, 이용 자격, 실제 지원금은 운영 기관에 확인해야 합니다.
자료를 갱신하려면 `chatbot/welfare/data`의 JSON을 같은 형식으로 교체하고 서버를 재시작하세요.

## 검증

```powershell
.venv/Scripts/python.exe -m unittest discover -s chatbot/tests -v
.venv/Scripts/python.exe -m unittest discover -s webapp/tests -v
cd frontend
pnpm run build
```

자동 테스트는 외부 AI를 실제 호출하지 않습니다. AI 스트리밍과 실패 전환은 모의 클라이언트로 검사합니다.
2026-10-07 코드 이식 후 원본 테스트를 포함한 25개 자동 테스트가 통과했으며, 별도로 팀 화면에서 실제 OpenAI 답변과 출처 표시를 확인했습니다.
기존 별도 Streamlit/CLI 분석 도구(`--streamlit`, `--chatbot`, `--chatbot-cli`)는 유지합니다.
