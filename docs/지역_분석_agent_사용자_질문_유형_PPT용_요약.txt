지역 분석 agent가 답하는 사용자 질문 유형


1. 화면에 있는 정보 질문

• 화면 요약
  - 선택 지역·기준월·연령대와 현재 상태를 한눈에 설명
  - 주요 지표가 무엇이 늘고 줄었는지 요약

• 이상신호 탐지 이유
  - 전화·문자·평일 이동·휴일 이동 중 어떤 지표가 기준과 달랐는지 설명
  - 자료가 충분했는지, 과거와 비교할 수 있었는지 안내

• 화면 기능·지표 설명
  - 탭·카드·그래프의 역할과 숫자 읽는 법 설명
  - 100 기준선, 증가·감소, 비교 기준을 쉽게 풀이


2. 화면에 없는 정보 질문

• 이후 변화 추이
  - 탐지 이후에도 계속 변했는지, 다시 회복됐는지 확인

• 보조 맥락 설명
  - 소비·날씨·계절 변화와 함께 비교
  - 단, 보조 자료만으로 원인을 단정하지 않음

• 추가 자료 안내
  - 다른 기간·연령대·지역·설문 자료 등 추가 확인 항목 제안


3. 자료 근거 확인 질문

• 원본 데이터·출처 확인
  - 지표별 자료 출처와 원본 종류를 구분해 설명

• 계산 기준·자료 한계 확인
  - 비교 기준, 판정 기준, 자료 부족 여부 안내
  - 지역·연령대 집계이며 개인 진단이 아님을 설명
