# 집단별 대시보드 연동

2026-10-08 구현. 기존 React 종합 현황에서 동·연령·성별·월별 브리핑을 연다. 탭 추가·중복 방지·닫기·키보드 전환을 지원하며, 오른쪽은 조사 파일과 도우미를 전환한다. 탭 간 이동 시 대화와 입력을 유지한다. 다른 메뉴로 이동하거나 새로고침하면 열린 탭과 대화는 초기화된다. 검토 메모 초안은 로컬에, 저장한 메모는 사용자와 집단별 SQLite에 보관한다.

## 실행

프로젝트 루트에서 기존 `.env`의 DB1/DB2 연결 설정을 사용한다. 키나 비밀번호는 코드에 포함하지 않는다.

```powershell
.venv\Scripts\python.exe -m db.group_repository --build --publish
cd frontend
npm run build
cd ..
.venv\Scripts\python.exe -m webapp.server --port 8514
```

원자료가 변경된 경우에만 첫 명령을 다시 실행한다. 입력은 `data/processed/age_pop.csv`, `wkdy_pop.csv`, `time_pop.csv`와 `shared/data/flow_region_codes.csv`다. 생성 파일 `data/processed/group_dashboard.json`에는 출처 파일의 SHA256과 집계 버전이 포함된다. `db1.group_flow_snapshots`에 새 버전을 추가하며 기존 분석 테이블을 덮어쓰지 않는다. 런타임은 DB1 스냅샷을 조회하고 연결 실패를 가상 데이터로 대체하지 않는다.

## 연결 범위

- 강남구 22개 동 × 6개 연령대 × 2개 성별 × 2025년 7~12월 = 1,584개 집단·월. 월별 264개 집단이다. 이는 위험 후보 수가 아니다.
- 연령·성별 유동량은 `age_pop`을 집계한다. 값은 원자료 유동량이며 고유 인원수·주민 수·고립 위험도가 아니다.
- 전월 변화율은 두 달에 공통으로 관측된 BLOCK_CD·X_COORD·Y_COORD 격자의 평균끼리 비교한다. 전월이 없거나 기준값이 0이면 산출하지 않는다. 월별 추이 그래프는 각 월 전체 관측 격자 평균이므로 지표 범위를 함께 표시한다.
- `wkdy_pop`과 `time_pop`은 지역 전체의 별도 집계다. 선택한 연령·성별의 요일·시간별 행동으로 해석하지 않는다. 요일은 7개 요일 평균=100, 시간은 최댓값=100으로 표시한다.
- Analysis1 지역 유형과 Analysis2 동 단위 근거는 기존 DB1 테이블에서 조회한다. 집단별 통화·문자 탐지 결과는 현재 미연결이다. 이를 연결하려면 원천 통신자료의 집단 단위 전처리와 탐지 검증이 추가로 필요하다.
- 지역 코드 1123074는 현재 명칭 개포3동으로 표시한다. 기존 분석 메뉴의 과거 명칭 일원2동과 이동 시 매핑한다.

## 업무와 도우미

`/api/groups` 아래에서 목록·상세·검토 메모·사업 후보·대화를 제공한다. 기존 로그인과 지역 권한을 적용하고, 메모 저장 시 데이터 버전이 바뀌었는지 확인한다. 메모 저장소는 `db/runtime/group_reviews.sqlite3`다.

사업 검토는 사용자가 선택한 지원 목적과 DB2 사업 설명의 관련어를 비교하는 초기 후보 검색이다. 연령·성별 자격 판정이나 검증된 개인별 추천 모델이 아니다. 대상·선정 조건·신청 방법·원문 링크를 제시하고 누락 정보는 확인 필요로 표시한다. 기존 업무/보고서의 상태를 자동 변경하지 않는다.

도우미 기본 모드는 외부 AI 호출 없이 조회된 수치와 자료 범위를 설명한다. 기존 OpenAI 연결이 설정되어 있으면 사용자가 AI 해석 모드를 선택할 수 있다. 전송 시 현재 집단 집계와 최근 대화가 기존 LLM 클라이언트로 전달된다. 실제 외부 LLM 호출은 이번 검증에서 실행하지 않았다.

## 검증

```powershell
.venv\Scripts\python.exe -m unittest db.tests.test_group_repository
.venv\Scripts\python.exe -m unittest discover -s webapp/tests
node --test frontend/tests/group-tabs.test.mjs frontend/tests/briefing.test.mjs frontend/tests/draft-store.test.mjs
```

공통 격자 계산·결측/0·중복/음수·집단 범위·메모 분리·권한·버전 충돌·탭 동작을 검증했다. 실제 DB1 조회와 브라우저의 복수 탭 전환, DB2 후보 조회도 확인했다. 경진대회 요구사항의 예측·분류 모델 성능 평가를 이 화면 구현만으로 충족하는 것은 아니다.
